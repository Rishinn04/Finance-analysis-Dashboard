# Finance-analysis-Dashboard
The Finance Analytics Dashboard is an interactive Power BI report designed to help users analyze financial transactions and monitor key performance indicators across time, transaction status, customer segments, states, transaction types, and gender. It brings important financial measures into one place so stakeholders can explore trends, compare performance, and support data-informed business decisions
## Tech Stack
Power BI Desktop 

## Business Problem

The management team needs a centralized way to monitor transaction growth and financial performance. Without a consolidated view, it can be difficult to compare monthly transaction amounts, identify failed or pending transactions, understand customer segment contributions, compare state-wise performance, and track fees and taxes.

## Goal of the Dashboard

- The dashboard aims to provide an interactive analytical view that helps stakeholders:
- Monitor key financial KPIs and year-over-year performance changes.
- Identify high-performing customer segments and states.
- Analyze monthly transaction patterns and status distribution.
- Compare transaction types using amount, fees, tax, and transaction count.
- Explore customer demographics and filter results by year, occupation, category, and dynamic measure.

## Walkthrough of Key Visuals

### Main KPIs
- Total Amount – Total transaction amount processed, with a year-over-year growth comparison.
- Total Transactions – Total number of transactions, with yearly transaction-volume changes.
- Average Transaction Value – Average amount per transaction.
- Total Fees – Total fees collected from transactions.
- Total Tax – Total tax generated from transactions.
  
### Charts and Analysis
- Total Amount by Month (Line/Area Chart): Shows monthly transaction amount trends and helps reveal increases, decreases, or seasonal patterns.
- Total Amount by Transaction Status (Donut Chart): Compares amounts associated with Success, Failed, and Pending transactions.
- Total Amount by Customer Segment (Horizontal Bar Chart): Compares Retail, Premium, SME, Corporate, and Wealth segments.
- Total Amount by State (Horizontal Bar Chart): Compares transaction amounts across states to highlight regional differences.
- Transaction Type Analysis (Matrix/Heatmap): Compares Amount, Fees, Tax, and transaction count across Bill Payment, Card Payment, Deposit, Fee Charge, Interest Credit, Investment, Loan EMI, Refund, Transfer, and Withdrawal.
- Total Amount by Gender (Donut Chart): Compares transaction amount contribution for Male and Female customers.

### Interactive Filters

- Year – Filters the analysis to a selected year.
- Dynamic Measure – Allows users to switch the measure being analyzed, if configured in the report.
- Occupation – Filters results by customer occupation.
- Category – Filters the analysis by the selected category.
